## Safe Daily Pattern

1. The GitHub health check validates local toolkit structure.
2. The existing 09:00 and 18:00 casting workflow performs public research within the daily source cap.
3. Jules may perform a single repository-maintenance task after GitHub access is connected in its own interface.
4. Gemini Spark or Workspace Studio may perform one internal material-readiness report after the selected personal Google account is verified.
5. Antigravity is used for on-demand local repository development, not broad internet outreach.

## Hard Boundaries

No scheduled component may publish a video, send a DM or email, submit an application, accept a contract, pay a fee, create an ad, share Drive files externally, or message casting contacts. It may not invent profile facts or represent an existing social Reel as a role-specific self-tape.

## Required Account Setup

The next setup operations are intentionally limited to opening Jules, Antigravity, and the Gemini/Workspace surfaces. Each one needs an accessible signed-in session before the corresponding internal task can be created.

# Jules Daily Maintenance Prompt

Use this prompt only after connecting the `acting-career-automation` repository in Jules.

> Review this repository for safe, repository-local maintenance only. Check Python scripts for syntax errors, validate the CSV header against the documented schema, inspect documentation for broken internal paths, and identify small improvements to templates, test coverage, or workflow reliability. Do not access social-media accounts, send messages, submit applications, publish content, pay fees, modify user data, or add unverified casting leads. Make changes only in a new branch or pull request, summarize every change, and leave the final merge decision to the repository owner.

## Suggested Cadence

Run once each day after the GitHub Actions health check. Do not schedule a second Jules task that performs public casting research; that work belongs only to the twice-daily casting workflow.

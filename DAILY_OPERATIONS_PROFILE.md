## Purpose

This is the repository's single daily reference for the acting-career automation. GitHub holds the durable code, workflow definitions, and internal operating rules. Terminal tools and connected Google services use these repository assets for internal analysis, validation, preparation, and storage.

## Factual Profile and Material Boundary

The reusable profile package remains incomplete until real, current material is provided. The required fields are current photographs, a headshot, a short introduction video, and a factual profile containing only genuine name, playing age, city and availability, height, languages, contact details, and verified skills or credits. Do not invent or infer any profile detail.

The Instagram Reel `CMcBy1JhbYk` is an optional general portfolio link only when a verified brief explicitly permits it. It is never a self-tape, showreel, role-specific audition, or eligibility proof.

## Non-Outbound Safeguard

No component may send an email, direct message, WhatsApp message, application, payment, post, document, video, portfolio link, or file externally. Any future external submission requires a complete truthful package and a context-specific final safeguard.

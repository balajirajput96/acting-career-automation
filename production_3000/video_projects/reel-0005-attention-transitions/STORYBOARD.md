# Storyboard — Reel_0005: Attention During Transitions

## Video direction

The edit uses a faceless editorial-science language. Each concept remains visible long enough to be read: luminous lines trace a shift in attention, an abstract tiled desk changes active state, and an evidence badge anchors limits. Motion is deliberately modest: route lines draw, panels slide, tokens glow, and one generated visual slowly pushes in beneath data-like overlays.

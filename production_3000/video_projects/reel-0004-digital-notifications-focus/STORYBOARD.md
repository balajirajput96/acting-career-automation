# Storyboard

| Time | Visual | Caption purpose |
|---|---|---|
| 0–9s | Original night-desk illustration; phone alert pulse heads toward notebook. | Hook without blaming the viewer. |
| 9–19s | Split pathway: alert pulse vs. current task, then a reaction-time dial. | Communicate the controlled task result. |
| 19–29s | Study-card visual with a large “context matters” limiter. | Preserve sample/generalization limit. |
| 29–40s | Two weekly calendars: alerts-on versus quiet-and-away; reported-symptom note. | Describe the two-week experiment without diagnosis. |
| 40–52s | Explicit “not ADHD causation / not treatment” bridge. | Prevent medical overclaim. |
| 52–60s | Three-step personal experiment: quiet, place away, write next step. | Voluntary takeaway and evidence end-card. |

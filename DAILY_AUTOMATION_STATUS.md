# Daily Automation Status

## Active Now

The repository includes a daily GitHub Actions toolkit health check and a safe maintenance prompt for Google Jules. The separate casting workflow runs twice daily at 09:00 and 18:00 Asia/Kolkata for public-source research, scam screening, shortlist updates, and factual material-gap reporting.

## Prepared for Account Setup

Gemini Spark or Workspace Studio can run one daily internal material-readiness task after the selected eligible Google account and the product interface are available. Antigravity can be used for local repository work after its user environment is authenticated. These services should not duplicate public casting research already performed by the casting workflow.

## Required Human-Supplied Inputs

Applications cannot become truthful or complete without the actor’s real profile data and current material: playing age, city/availability, languages, height, contact details, headshots, introduction video, and role-specific self-tapes or skill demonstrations.

## Guardrails

No component is configured to send messages, submit applications, publish videos, share files externally, pay fees, accept contracts, create ads, or use mass outreach. The toolkit is intentionally review-first and evidence-based.

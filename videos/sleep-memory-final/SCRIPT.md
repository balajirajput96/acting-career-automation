# Script — Sleep and Memory

Study karke raat bhar jagna smart shortcut lag sakta hai, but brain new information ko ek hi moment mein permanent save nahi karta. Learning ke teen parts samjho: acquire karna, consolidate karna, aur recall karna. Harvard aur NIH ki educational summaries ke mutabik, sleep ke baad new factual aur skill-based memories zyada stable banne mein support mil sakta hai. Iska matlab yeh nahi ki ek perfect night har test fix kar degi. But all-nighter ko strategy samajhna bhi strong plan nahi hai. Aaj ka practical step: padhai ke baad teen key points likho, phir apne normal sleep routine ko protect karo. Agar sleep ya memory issues lagatar hain, clinician se baat karo. Sources: NIH, Harvard Sleep Medicine, and Yale School of Medicine.

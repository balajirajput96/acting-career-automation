The non-outbound GitHub and casting-research components are active and validated. The remaining systems require their own accessible user interfaces before account-specific tasks can be created.

| System | Current blocker | Setup enabled after access |
|---|---|---|

| Workspace Studio / Drive / Sheets | The selected Workspace account must expose the intended Studio and Drive interfaces. | Create an internal material inventory flow limited to Drive/Sheets data and internal reports. |

## Activation Boundary

After an account interface loads, the setup should create only the documented internal/repository task. It must not enable automatic communication, public posting, application submission, payment, external file sharing, or ad creation.
